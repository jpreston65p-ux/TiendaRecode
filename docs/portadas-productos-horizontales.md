# Portadas horizontales de los productos anteriores

Se renuevan únicamente las portadas de los diez productos anteriores. El pack nuevo `Pack Scalito Aventuras` y las portadas de las tres colecciones permanecen sin cambios. Se conservan todos los nombres, descripciones, precios y enlaces de compra.

Creación con la herramienta integrada de imágenes y el Scalito de referencia aportado en la conversación. Cada producto tiene una acción y una escena distintas; no se exige llevar una Biblia. Son composiciones horizontales de 1536 × 1024 (3:2), no versiones verticales recortadas.

Las variantes JPEG de 400 y 800 píxeles de ancho se obtienen reduciendo el lienzo completo, con calidad 86. Las tarjetas compactas usan ancho completo y altura automática; no imponen la antigua altura fija ni recortan las ilustraciones. El banner y la carga diferida se conservan.
